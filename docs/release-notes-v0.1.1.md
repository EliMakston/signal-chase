# Signal Chase v0.1.1

Signal Chase v0.1.1 expands the offline Demo experience:

- Six curated music networks with 40 songs and 160 directed connections each.
- Random races across Easy, Medium, and Hard difficulties, with network selection and Surprise Me.
- Offline Custom races with local song search, directed-route validation, backtracking, and shortest-path benchmarks.
- Updated landing-page copy and SEO for the expanded Demo.

Live Last.fm lookup remains disabled pending provider approval. Demo gameplay
requires no account, network connection, or external music API.
